# Projet ToDoList
Projet de cours PHP POO todolist (DEV312503)

## Installer les dépendances :
```sh
composer install
```
## Créer un fichier .env
```env
DATABASE_USERNAME=root
DATABASE_PASSWORD=
DATABASE_NAME=todolist
DATABASE_HOST=localhost:3306
```

## Démarrer le projet
```sh
php -S localhost:8000 -t public
```
